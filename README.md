# 3h
Личный сайт визитка и портфолио для демонстрации проектов, навыков и стека технологий в сфере разработки Telegram ботов и Data Engineering.

## О проекте
Лендинг разработан для удобного представления профессиональных компетенций, контактов и будущих кейсов. Сайт полностью адаптивен и настроен для публикации через GitHub Pages. 

## Стек технологий
* **HTML5** - семантическая разметка.
* **Tailwind CSS** (через CDN) - стилизация и адаптивный дизайн.
* **JavaScript** - анимации появления (Scroll Reveal) и защита контента.
* **Шрифты** - локальный кастомный шрифт `TT Firs Neue`.

## Структура файлов репозитория
* `index.html` - главный файл разметки страницы со встроенными стилями и скриптами.
* `TT-Firs-Neue.ttf` - файл шрифта, необходимый для корректного отображения типографики.
* `README.md` - описание проекта.

## Особенности
1. **Защита контента:** Базовая JS-блокировка правой кнопки мыши, выделения текста и горячих клавиш консоли разработчика.
2. **Безопасность (CSP):** Настроен Content-Security-Policy для предотвращения XSS-атак.
3. **Производительность:** Минимальный вес страницы, использование современных форматов и плавная анимация.
